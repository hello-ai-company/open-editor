# OpenEditor 0.3.0-notes.4 — local candidate

Adds a machine-readable installed schema inventory, explicitly bound/permitted operations, capability/selection revisions, restrained idle proposals and safe structured link addition, href correction, internal page labels and unlinking. Prose is preserved: only short opening headings and explicit list cues are suggested by the visibly synthetic fixture. Installed DB/columns/HTML/Canvas descriptions do not grant executable bindings. This standalone note binds heading/list/title/placement and link operations only.

Existing structural automatic permission does not authorize links. Exact original URL wrapping/canonicalization has a separate per-note opt-in. Internal links, duplicate unlinking and meaning-changing href/label edits require explicit review. Unlinking retains quoted/displayed text and styles. Invented URLs, unknown/cross-sharing pages, unsafe schemes/credentials and opaque targets are rejected. Links are never fetched or claimed verified. All document/page/external content remains untrusted quoted context.

Trusted user approval is persisted against the exact operation payload before commit. The host rechecks document/hierarchy/pins/selection/capabilities/permissions in one transaction with original/history, idempotent receipts and lost-ACK recovery. Atomic Undo refuses later edits/permission changes while allowing caret-only movement. Dismissal and Undo suppress the same proposal across revision/caret changes; preparation is idle-only, IME/visibility/stop-aware, bounded to 12 runs and at least 10 seconds between capability-aware preparations. The review sits below the editor and retains height after dismissal/approval; bounded bottom reserve keeps the caret visible at a short note's scroll limit. User input/selection/viewport intent always wins over delayed compensation.

The demo at `?organize=synthetic` uses separate `open-editor.synthetic-organization.v2` IndexedDB. Previous v1 browser notes and .0/.1/.2/.3 tarballs/manifests are retained. Public package source versions remain 0.2.0; only staged tarballs use .4. No real AI, external page requests, PersonalAI changes, installs, publishing or deployment are included. Production host/provider integration, native macOS IME and real model judgment remain unverified.

Contract: bundled `HOST-CONTRACT.md`. Final verification and actual screen evidence: `output/verification-notes4/` and `output/playwright/notes4/`. The adjacent manifest records the source HEAD, bytes, SHA-256 and isolated runtime/declaration checks. No claim of faster runtime is made against older Chromium/CPU-throttled measurements. Existing column code keeps its MPL-2.0 boundaries.
