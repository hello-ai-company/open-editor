# .30 Columnsと共通ブロック移動の改善候補

ローカル検証専用。基点は .28 `9b2a2e1ad31779124d5fa4578d5435ef761964dc`。公開・PA実画面への導入なし。

事前にブロック全体を選択しなくても、Columns全体・個々の列・列内の内容をそれぞれのグリップで動かせる。挿入線／空列の枠で移動先を示し、Escapeで取り消す。Alt＋矢印の代替操作と移動後のフォーカスを備える。本文からAlt＋Shift＋Mで移動グリップに移れる。一般のwidgetにも外側の移動グリップを用意し、内部の入力・描画操作はそのまま扱う。

Columnsメニューの「Add column」で2列から最大6列まで追加できる。追加後はメニューを閉じ、空列へのドロップを妨げない。幅の狭い編集領域では3〜6列を折り返し、最小幅では縦に表示する。ID・幅・順序・入れ子・未知metadataを保存する既存の形式は変更しない。

開いたHTMLソースや未適用の列幅を含むサブツリーを置き換える操作は保留し、入力を保持する。無関係なwidgetを一括置換しない。描画、コード選択／コピー、DB/HTMLのraw退避・固定operation・unknown復元・保存後の復旧は回帰確認した。
