# Notes .12 — public reading, property selection and dialog polish

Local candidate based on immutable .11 source `5f55c611d2fd06610280c04cde89c5a3e8dbe114`.
No release manifest, PersonalAI source, production data or previous candidate is replaced.

The standalone workspace fills the supplied width, including the left edge. The
example reserves PersonalAI chrome only with explicit `hostFrame=reference`.

This iteration adds optional public search/Ask-page panels, an authorized DB
navigation/paging/count projection and bounded preview, literal dictionary
references, readable history excerpts and proposal before/after presentation.
The public property-picker hook supplies choices to the existing field draft;
a separate scoped property.patch still commits. Computed values remain read-only.
Legacy user/location text and URL-file values require explicit valueMode configuration;
labels/URLs never become inferred identities. Four legacy link layouts and explicit
host-resolved media preview are available through the opt-in v2 feature.

The table dialog chooses 1–5 rows/columns and preserves automatic column positions
across JSON save/reload. New dialogs portal outside sticky contexts while remaining
inside the actual Notes owner. Scope/provider switching, cancellation, repeated
clicks and composition events have local regression coverage. Hover reading cards
now align to the sidebar boundary and allow pointer transfer/scroll before leaving.

The new synthetic route is `?notes=synthetic&classic&parity` (or `&parity=legacy`).
It has separately named local databases; no paid AI, real provider or production
record is used. Original/default/baseline routes and .0–.11 artifacts are retained.

This is not full Notes replacement. The 59-row ledger preserves every remaining
host/UI/legacy/CSS acceptance gate. All11 DB views, original native schema/gallery/
cover/emoji UI, selected-text AI/comment tools, actual Secretary provenance,
full35-image CSS equality and native IME/Safari/zoom remain unaccepted. Old Notes
must remain available. Journal common-body integration is consultation only.

See the accompanying host delta, verification report and machine-readable
`NOTES12-ACCEPTANCE.json`. Install only in an independent host acceptance candidate.
No npm publication, push, merge or deployment is part of this candidate.
