# OpenEditor 0.3.0-notes.3 — local candidate

Adds reusable free-writing note organization to editor-ai and the opt-in `NoteOrganizationCard` to editor-blocknote/react. Original body characters are preserved while selected paragraphs become headings/lists; titles come from original excerpts, and placement uses an existing authorized parent or root. Per-note permission is separate from ordinary suggestion approval. Manual titles and pinned parents are protected; only ambiguous placement asks for confirmation.

The provider-neutral host contract includes document/hierarchy/pin CAS, one atomic body/title/move/history transaction, idempotent operation receipts, durable pre-submit recovery, terminal operation fencing, lost-ACK lookup and matching-history Undo (including reload). Idle/IME/input/document-switch cancellation and reconnect races fail closed. Unknown blocks/columns/inert HTML widgets and existing Notes codecs are unchanged. Existing .0/.1/.2 artifacts are not overwritten. Public package source versions remain 0.2.0; only staged tarballs use this candidate version.

The standalone example at `?organize=synthetic` uses a visibly synthetic deterministic agent and isolated IndexedDB page tree. It includes original backup, failure fixtures and atomic Undo/keyboard operation. No real model, external service, PersonalAI modifications, installs, push, merge, deployment or publishing are part of this local phase. Production host/provider integration and native OS IME remain unverified.

Contract and host responsibilities: bundled `HOST-CONTRACT.md` (source: `docs/note-organization-host-contract.md`). Verification logs and browser evidence: `output/verification-notes3/`, `output/playwright/notes3/`. Runtime/browser checks use synthetic data; they do not establish production/model correctness. Source HEAD, byte sizes and SHA-256 values are recorded in the adjacent candidate `manifest.json` after packing. Independent column code keeps its existing MPL-2.0 license boundaries.
