# Notes .14 — reviewed page design and selected text editing

Local-only candidate following immutable .13. No push, merge, publish, deploy,
paid model call, authentication change, old UI removal or original data mutation.
Standalone retains x0/full supplied width; `hostFrame=reference` is explicit.

The common Notes UI now displays host-mapped safe cover images, twelve style
previews and a visual gallery with an optional bounded scoped cover catalog.
Selections are staged; Apply sends one reviewed metadata.patch through the
existing revision/receipt controller. Close/unmount retains the draft; Cancel
clears only the unchanged own input. Original and unknown metadata remain intact.
An optional existing renderCoverControl override remains supported.

Selected text has an explicit opt-in host AI service, source/suggestion review,
Reject, Replace and immediate unsaved-body Undo. Single-block public BlockNote
range tickets bind scope/target/body/revision/selection generation and writer
lifetime. No proposal writes automatically. Comments use the existing canonical
block-level comment.add writer. The SDK does not invent fixed character anchors,
AI permission, web access, providers, billing consent or durable Undo receipts.

See the host delta, PA contract, verification and machine-readable 59-row ledger
in this candidate. Full59 replacement/full35 image/CSS equality remain false.
Actual PA adoption is separate. The original 24 cover presets/floating toolbar,
all cover variants, upload/Unsplash, multi-block rich suggestions, native IME,
Safari, real DB writes/entitlements and legacy workflows remain acceptance gaps.

Synthetic preview: `?notes=synthetic&classic&parity=design`, using separate
parity14-v1 IndexedDB records and deterministic local services/images. Gallery
and selection input are controller-local; browser-restart durability is not claimed.
