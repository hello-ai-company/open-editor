Isolated candidate based on accepted .21, source 9306d2b4203ab0b67aa83617c1dff8bdf8f72eff. No original-store writes, AI calls, provider grants, publication or live-host replacement.

Clicking a Whiteboard tool's SVG child could focus ProseMirror and select the outer block. Native/legacy interactive block specs now declare `selectable:false`; Notes document-widget features also install a public input boundary for host-defined block specs rendering the shared widgets. Native controls retain default behavior and React propagation. Inline text and drag/drop retain editor handling. This fixes the confirmed SVG/outer-selection conflict, not a claim that every vector operation was blocked. Whiteboard still has no text tool. Drawing help is collapsed; its width stays stable as stroke counts change.

Columns no longer reserve permanent configuration panels or nested vertical frames. Hover and keyboard focus reveal labeled options; Escape closes the panel and returns focus. Touch shows 44px targets. Popovers do not move content. Reordering updates option labels and movement availability. A concurrent width change retains the local slider input and requires explicit review. Genuinely empty columns retain a target and an explicit Add text action; opening an empty document does not write placeholder paragraphs. HTML loses its redundant outer frame and moves technical preview details behind a disclosure. Its source draft, explicit Apply/Cancel, inert script preservation and sandbox policy remain intact.

Existing .21 publication guards, retained columns IR, .20 selection/caret behavior and .19 interactions remain. This is a scoped SDK candidate, awaiting PA owner adoption and actual-host acceptance.
