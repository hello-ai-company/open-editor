# .33 PA acceptance boundary

共通候補は .31のscoped coediting port、.32のpublic pair resize/gutterを含みます。coeditingの接続・AI policy・canonical revision・approval/audit/receipt/fixed-ID lookup・unknown reconciliation・process restart後の新draft/Undo durabilityはPA側の受入ゲートであり、合成UI結果で代替しません。

PA5501への .32/.33導入や実ホストのprovider接続は本候補作業ではしていません。12ツールはhost delta表のschema/features・scoped media/insertion/database/shared bindingsを点検してください。未接続時はdisabledのままで正しい挙動です。DB view referenceの挿入・編集・本文保存とDB row/resourceの保存は別です。権限/承認/保存先を実装せず、フラグだけで有効化しないでください。

単独OpenEditorの左固定枠はPA shell配置で解消する必要があります。共通hideNavigationは空列と起動ボタンを出しませんが、hostの予約幅までは除去しません。ユーザーの「エディターの下にデータベース」の位置情報は保持。具体的画面URLとどのsurfaceか未特定なので、原因や不要性を断定せずDBを削除していません。

実素材upload/Unsplash/API、PDF解釈・音声/動画再生、実DB row変更、Safari/物理touch/ネイティブIME、従来CPU4計測は未確認。KaTeXのsymlink依存fontにVite allow-list警告があり、fontの実画面表示を検証済みとしません。server/security設定は変更していません。

本候補は独立したローカル成果物です。公開・push・merge・PAへのインストール・実AI/API・課金・認証設定変更は実施していません。既存 .31/.32 と旧成果物・schema29 WIP は保持しています。
