# Notes .20 PersonalAI boundary and recovery contract

Shared SDK only; host source is read-only. Parent owns adoption into PersonalAI. Accepted .19 and the independent notes19-layout host containment stay protected. Canonical storage, inlineContent synchronization, UUID block ownership, CAS receipts, Undo/Redo, authentication, security and database contracts are unchanged.

Ordinary insertion/AI replacement remains unsaved until a validated canonical receipt. Export completion says a file was prepared, not that the canonical document was saved or a disk write was confirmed. Unknown outcomes remain persistent with read-only lookup; no resend. Saving exposes cancellation with existing controller semantics. Errors never become success because of text matching. Pending form input, retained AI input and unsaved Undo remain accessible after transient expiry. Proposal opening is explicit and closing retains mounted input; actual apply remains controlled by the existing review callback.

No original-store synthetic writes or user-tab reloads. Isolated5206 API and synthetic local browser data only. Concurrent user/owner store updates must not be reverted; whole-store immutability is not claimed. Current .20 is a deliverable for adoption, not evidence that the user's live screen already uses it.
